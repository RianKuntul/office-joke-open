Entry for the make.fun competition **Make the AI Judge Laugh: the Office Joke Open**
(`u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232`, $2 prize).

`main.ts` (Node 22, readable TypeScript) writes one original one-line office
joke — a single line of at most 200 characters — to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR` is honored when set). A read-back gate refuses anything
outside 1–200 characters, anything that is not a single line, or a blank line.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/office-joke-open-out node main.ts
```
